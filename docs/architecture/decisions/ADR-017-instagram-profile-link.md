# ADR-017: Instagram Profile Link Without OAuth in MVP

- **Status:** Accepted
- **Decision:** MVP supports a user-managed Instagram username/profile URL only.
- **Context:** This is low complexity and provides a useful external portfolio link without API approval, account-type, or permission dependencies.
- **Consequences:** No media import, publishing, insights, or OAuth in MVP. Revisit only after user demand and current platform documentation are reviewed.
