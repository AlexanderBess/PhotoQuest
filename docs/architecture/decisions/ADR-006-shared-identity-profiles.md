# ADR-006: Shared Identity and Profiles

- **Status:** Accepted (wording updated 2026-11-03)
- **Decision:** Identity and profile data are shared platform capabilities.
- **Context:** Community, Explore, Learning and Coach (MVP) and future Academy modules refer to the same user identity.
- **Consequences:** Authentication credentials and roles (Identity) remain separate from public profile fields and visibility settings (Profiles).
